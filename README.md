# ConnectEd

ConnectEd (**Connect**ion **Ed**itor) is a diagramming tool for HDL designers. Similar to an EDA schematic editor, it allows designs to be built by from hierarchical blocks, symbols (e.g. simple gates and vendor primitives), ports, wires and busses.

ConnectEd supports both VHDL and Verilog:
- diagrams may be exported to HDL
- blocks may be created by parsing interfaces in existing HDL source

**This project is in an early stage of development.**

## Acknowledgements

ConnectEd is written in Python, and built on the PyQt6 Python bindings for Qt.
